    custom firmware install steps

    Unofficial, and at your own risk. open-field isn't made, endorsed or supported by Teenage Engineering, and it isn't affiliated with them. A firmware change can leave a unit unable to start for good, and installing this will void the warranty of your device. Whether to do it is your decision alone.

    The install needs a computer: Windows, a Mac or Linux. It won't work on a phone or a tablet.

    Installing from a Mac has been reported once, in Chrome, on an earlier release. This one hasn't been tried there.

    7. 7

      install the custom firmware

      1. Restart your OP-1 in bootloader mode.
        WARNING, do NOT restart your OP-1 in normal mode until you've finished the install, otherwise you'll have to start again. Turn your OP-1 off, then turn it on while holding COM again.
      2. Press 3 and the developer menu opens. Press 4, the entry write os to boot partition. Never press 1 in there: it's a factory reset.
      3. The screen reads looking for /os.ldr and then stands still for up to half a minute. Don't touch your OP-1 and don't switch it off while it's still.
      4. When firmware written ok! shows, you can switch your OP-1 field off.
      1hold COM and switch on23 for the developer menu34 writesnever 1

      If small text shows up instead, naming a source file and a line (rsi.c and a number), the write stopped before it could install the firmware. You can switch it off. Your firmware is intact, and your OP-1 still runs the firmware it had before. You can run the install again from step 1.

      If small text shows up instead, that hasn't been seen on bootloader 1000.2.0. Don't count on the write having stopped or on your firmware being intact. Ask on open-field's GitHub before you try again.

    8. 8

      start your OP-1

      You can now start your OP-1 field normally. If the custom firmware installed properly, the splash screen will read 1.7.3 - open-field 0.3. If at any point your device fails to start (for example because of a faulty .pack you installed), you can hold the help key while starting to bypass the custom firmware and start as the original firmware.

      You can now start your OP-1 field normally. It's back on the original firmware, and the splash screen reads 1.7.3 with nothing after it.
